# Experiment commands (essential)

The one command that reproduces each experiment, plus setup. All flags, examples and arguments: [commands-full.md](../runbook/commands-full.md). Interactive: `docs/dev/runbook.html`. Generated by `uv run python -m ants.evalkit.runbook build` from `docs/runbook/commands.json`.

Rule of thumb: start the services, run with a small `--token-budget`, view the run, then scale up. A run resumes if you repeat the same `--out`.

## Perturbation preview (System 2 hook)

Does a working program survive hand-picked perturbations? (friction x0.4, bowl shift, actuation noise + latency) Details: `docs/results.md`.

**Run a program under a perturbation**

```bash
cd ASPIRE && LIBERO_CONFIG_PATH=$PWD/.libero TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1 MUJOCO_GL=egl PYOPENGL_PLATFORM=egl EGL_PLATFORM=device CUDA_VISIBLE_DEVICES=0 .venv-libero/bin/python ../tools/aspire_launch.py ../data/runs/perturb_preview/friction04.json -- run \
    --benchmark libero-pro \
    --suite libero_goal_swap \
    --task-id 8 \
    --seed 51 \
    --init-mode seeded \
    --program PATH/program.py \
    --output-root ../data/runs/perturb_preview/out \
    --max-steps 2000 \
    --camera-width 800 \
    --camera-height 512
```

**Real-size scene (bowl x1.227, plate x1.855)**
