# ANTS Studio UI review (2026-11-04)

Reviewed the merged window (`observability/live-console` at `5ee9b9f`) on a real server, in headless Chrome over the DevTools protocol, at 1440x1000 and 1910x1100, light and dark. The Synthesizer's `muse exec` was stubbed and the backend was the mock world, so no tokens and no GPU were used. Real `/policy-dev` requests were intercepted in the browser or replaced by injected events. Screenshots are in `/tmp/ui_review/` (not kept in the repo).

Final state: no JS errors, no failed requests except the intended 409 from New session during a run.
